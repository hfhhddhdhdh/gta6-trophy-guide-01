Offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI: cited guides in original words, a six-stage platinum roadmap, missable flags built from the official descriptions, a spoiler setting that hides story trophies until earned, and progress saved in the browser with export/import. No network needed — open it and it works.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. Or open `app/index.html` from any static file server with `app/` at its root.
